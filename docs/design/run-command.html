Pick

A. The output gets the page's full width (logs are wide, and the 380px list in B squeezes both commands and output), and it lands right under the command box: type, Enter, the new run is the top row, selected, and its output opens there when it ends. It is the Audit table's open-a-row pattern, so nothing new to learn, and the table keeps every column the history needs (status, exit, who, when, duration) that C has to drop. C reads like a live terminal, which the tab is not: runs are background jobs whose output arrives at the end, so a prompt promises an interactivity it can't keep.
