Pick

Header B and review A. B puts the lock where nobody misses it on the one environment that matters, with who and why, and links to the requests waiting there; the strip only exists while locked, so unlocked environments look as today. Review A is an inbox: the list stays visible while deciding, the detail shows the exact call, its arguments as a diff, what changed since, and both decisions next to a comment. It handles several requests in a row without page loads.
