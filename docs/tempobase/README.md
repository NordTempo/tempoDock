# tempoBase guide

tempoBase is Tempo Dock's database panel as a standalone, self-hosted
server: browse, query and safely change Postgres data, with users, a data
access policy, an audit log and an MCP endpoint for agents. It is built
from this repository ([ADR 0024](../decisions/0024-tempobase-standalone.md)).

The guide's pages are written in workstream D of ADR 0024.
