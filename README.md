# platform

Working name. A self-hosted, Railway-style deploy platform for a single VPS.

Deploy Docker apps from a CLI or a web UI, with projects, environments,
services and variables. Built so AI agents can deploy safely without being
able to break or destroy things. Your servers, your data, no per-seat pricing.
